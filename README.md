# Expense Tracker - React Application

A modern expense tracking application built using React and Vite.  
The application allows users to manage their income and expenses, track balance, and maintain transaction history with a clean and responsive dashboard interface.

This project was developed as part of the **Frontend AI Engineering Internship** using AI as a development assistant for implementation, debugging, UI improvement, and documentation.

---

# Features

## Transaction Management

- Add income and expense transactions
- Delete existing transactions
- View transaction history
- Automatically update balance calculations

## Financial Summary

- Display current balance
- Track total income
- Track total expenses
- Format currency values for better readability

## Data Persistence

- Transactions are stored using browser local storage
- Data remains available after refreshing the application

## User Experience

- Form validation for incorrect inputs
- Empty state message when no transactions exist
- Responsive design for different screen sizes
- Smooth animations and hover interactions
